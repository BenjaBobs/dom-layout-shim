# Code of conduct

DOM Layout Shim welcomes constructive participation from people of all
backgrounds and experience levels.

Contributors are expected to:

- Discuss ideas and disagreements respectfully.
- Critique work rather than people.
- Assume good intent while remaining open to correction.
- Avoid harassment, discrimination, threats, and unwanted personal attention.
- Respect privacy and do not publish another person's private information.

These expectations apply in repository issues, pull requests, reviews, and
other project spaces.

The maintainer may edit or remove contributions and restrict participation when
conduct is harmful, disruptive, or unsafe. Report conduct concerns through a
private contact method listed on the
[maintainer's GitHub profile](https://github.com/BenjaBobs). If no private
contact method is available, use GitHub's abuse-reporting tools. Do not include
sensitive personal information in a public issue.
