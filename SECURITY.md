# Security policy

## Supported versions

DOM Layout Shim is currently pre-1.0. Security fixes are applied to the latest
published version. Older versions are not maintained separately.

## Report a vulnerability

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/BenjaBobs/dom-layout-shim/security/advisories/new).
Include:

- The affected version or commit.
- The environment and DOM implementation involved.
- Reproduction steps or a minimal repository.
- The expected and observed impact.
- Any suggested mitigation, if known.

Do not open a public issue for an undisclosed vulnerability. If private
reporting is unavailable, open a public issue that asks the maintainer to
establish a private contact channel without including sensitive details.

You should receive an acknowledgement within seven days. Remediation timing
depends on severity and complexity. The maintainer will coordinate disclosure
and credit with the reporter.
